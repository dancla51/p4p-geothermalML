# Description
This folder contains all of the work completed by Daniel Clark during his part 4 project in 2024, about inferring geothermal data history using data-driven modeling. 

The majority of code is in the form of Jupyter notebooks, which were edited using ARDC Nectar Jupyter Notebook service. To run, view or edit these notebooks, see the 'Notebooks/Final_Jupyter_Notebooks' path.

The 'ManualDataManipulation' folder contains our efforts at understanding the previous manual process that we are aiming to replace by manually matching as well as we can to some provided simulated data.

The 'LLSOFormulationOnPaper' shows how the LLSO Model was designed, and how the data as input to the LFO model needs to be arranged within the relevant matrices to accurately represent the problem.

Also within this compendium, you can find data that was used, images that were produced, several backups of old code, the final report produced from this research, and a number of references and other resources.
